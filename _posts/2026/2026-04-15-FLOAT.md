### 0. 前言

在计算机中，**浮点数（ floating-point ）**通常遵循 **IEEE 754 标准**，一个浮点数一般由**三部分组成**：

- **符号（ Sign ）位**
- **指数（ Exponent ）位**
- **尾数（ Mantissa）位**

以**单精度 float（ 32 位）**为例：

| 部分     | 位数 | 说明            |
| -------- | ---- | --------------- |
| Sign     | 1    | 0 正数 / 1 负数 |
| Exponent | 8    | 指数            |
| Mantissa | 23   | 尾数            |

计算一个浮点数值的数学表达式是：

$$
(-1)^{\mathrm{S}} \times \mathrm{M} \times 2^{\mathrm{E}}
$$

其中：

- $\mathrm{S}$ = 符号位
- $\mathrm{E} = \mathrm{exponent} - \mathrm{bias}$ $(\mathrm{bias} = 127)$
- $\mathrm{M}$ = 尾数部分（根据不同类型而不同）

单精度 float 主要分为**三大类**，它们分别是：

- **规格化数（ Normalized Number ）**
- **非规格化数（ Denormalized Number ）**
- **特殊值（ Special Values ）**

### 1. 规格化数（ Normalized Number ）

#### 1.1. 定义

当**指数位既不全是 0 ，也不全是 1** 时，表示的是**规格化数**。这是最常见的浮点数形式。指数位：

$$
1(00000001) \leq \mathrm{exponent} \leq 254(11111110)
$$

也就是：

$$
00000001 \sim 11111110
$$

8 位指数被认为是一个**无符号整数**，但其实际数值需要减去一个**偏移量（ bias ）**，对于单精度 float ，偏移量是 **127**，也就是说：

- 如果指数位的二进制是 $e$ ，那么实际的指数值 $\mathrm{E} = e - 127$
- 范围：由于 $e$ 的范围是 1 到 254 ，所以实际的指数值的范围是 -126 到 +127

#### 1.2. 尾数部分

在规格化数种，尾数部分的整数部分永远是 **1** ，也就是说规格化数尾数部分实际表示的值是：

$$
\mathrm{M} = 1.\mathrm{fraction}
$$

其中 $\mathrm{fraction}$ 是 23 位小数部分的二进制表示

所以规格化数的实际值公式为：

$$
(-1)^{\mathrm{S}} \times (1 + \mathrm{fraction}) \times 2^{(\mathrm{exponent} - 127)}
$$

#### 1.3. 示例

假设：

$$
\begin{aligned}
&\mathrm{S} = 0 \\
&\mathrm{Exponent} = 130 \\
&\mathrm{Fraction} = 01000000000000000000000
\end{aligned}
$$

那么：

$$
\begin{aligned}
&\mathrm{E} = 130 - 127 = 3 \\
&\mathrm{M} = 1.01_{\text{2}} = 1.25
\end{aligned}
$$

那么实际值为：

$$
1.25 \times 2^3 = 10
$$

#### 1.4. 特点

规格化数是 **float 的主要数值范围**

### 2. 非规格化数（ Denormalized Number ）

#### 2.1. 定义

当**指数位全为 0** 时，表示的是**非规格化数**。也就是说指数位：

$$
00000000
$$

#### 2.2. 尾数部分

与规格化数不同，非规格化数的整数部分永远是 **0** ，也就是说非规格化数尾数部分实际表示的值是：

$$
\mathrm{M} = 0.\mathrm{fraction}
$$

#### 2.3. 指数

虽然指数位是全 0 ，但为了数值的平滑过渡，非规格化数的指数**固定为 -126** ：

$$
\mathrm{E} = 1 - \mathrm{bias} = -126
$$

所以非规格化数的实际值公式为：

$$
(-1)^{\mathrm{S}} \times (0 + \mathrm{fraction}) \times 2^{-126}
$$

#### 2.4. 为什么要引入非规格化数

因为规格化数的尾数必须 $\geq 1$ ，指数最小是 -126 ，所以规格化数的最小值是：

$$
1.0 \times 2^{-126}
$$

如果计算出的数值比这个值还要小的话，会直接归零，导致精度突然丢失（从很小的非零数直接跳变到 0 ，也就是发生**下溢出（ Underflow ）**）。非规格化数就是为了填补 0 附近这段空白，实现**逐渐下溢（ Gradual Underflow ）** ，非规格化数提供：

$$
0 < \mathrm{value} < 2^{-126}
$$

**最小的正 float**：

$$
0.00000000000000000000001_{\text{2}} \times 2^{-126} = 2^{-23} \times 2^{-126} = 2^{-149} \approx 1.4 \times 10^{-45}
$$

### 3. 特殊值

当**指数位全为 1** 时，表示**特殊情况**

#### 3.1. $\pm \infty$ （ Infinity ）

当**指数位全为 1 ，尾数位全为 0** 时，表示的是 $+\infty$ 或者 $-\infty$ ，符号由 $\mathrm{S}$ 决定。此时：

$$
\begin{aligned}
&\mathrm{Exponent} = 255 \\
&\mathrm{Fraction} = 0
\end{aligned}
$$

无限大数值一般由**除零**或**数值溢出**产生

#### 3.2. NaN （ Not a Number ）

当**指数位全为 1 ，尾数位不是全 0** 时，表示的是**非法数学结果 NaN** 。此时：

$$
\begin{aligned}
&\mathrm{Exponent} = 255 \\
&\mathrm{Fraction} \not ={0}
\end{aligned}
$$

在 IEEE 754 种， NaN 分为**两种类型**：

- **Quiet NaN （ qNaN ，静默 NaN ）**
- **Signaling NaN （sNaN ，信号 NaN ）**

##### 3.2.1. Quiet NaN （ qNaN ）

当运算出现非法结果时，硬件通常生成 qNaN ， qNaN 的特点是：

- **运算不会产生异常中断**
- **NaN 会继续静默传播**

例如：

```cpp
float a = 0.0f / 0.0f;  // a = NaN
float b = a + 0.5f;     // b = NaN
```

通常 qNaN 的 $\mathrm{Fraction}$ 的最高位为 1 ，也就是：

```
S | Exponent | Fraction
0 | 11111111 | 1xxxxxxxxxxxxxxxxxxxxxx
```

##### 3.2.2. Signaling NaN （ sNaN ）

用于主动触发浮点异常，当其参与计算时，会产生 `floating-point exception` ，通常用于调试

通常 sNaN 的 $\mathrm{Fraction}$ 的最高位为 0 并且 $\mathrm{Fraction} \not ={0}$ ，也就是：

```
S | Exponent | Fraction
0 | 11111111 | 0xxxxxxxxxxxxxxxxxxxxxx
```

##### 3.2.3. NaN 的一个重要性质: $\mathrm{NaN} \ne \mathrm{NaN}$

**NaN 不等于任何值，包括自己** ， NaN 表示的是“未定义的结果”，它由不同的非法运算产生，并没有数学意义，所以 **NaN 与任何值比较都为 false，包括它自己**

### 4. 几个例子

#### 4.1. `1234.6789`

我们用 IEEE 754 单精度浮点数（ 32 位 float ）来把 `1234.6789` 抓换成二进制存储：

**第一步：确定符号位**：

`1234.6789` 是正数，所以符号位是 `0`

**第二步：整数部分转二进制**：

整数 `1234` 转换为二进制：

```
1234 / 2 = 617    余 0
617  / 2 = 308    余 1
308  / 2 = 154    余 0
154  / 2 = 77     余 0
77   / 2 = 38     余 1
38   / 2 = 19     余 0
19   / 2 = 9      余 1
9    / 2 = 4      余 1
4    / 2 = 2      余 0
2    / 2 = 1      余 0
1    / 2 = 0      余 1
```

倒序得到：

$$
1234 = 10011010010_2
$$

**第三步：小数部分转二进制**：

小数 `0.6789` 用**乘 2 法**：

```
0.6789 × 2 = 1.3578  -> 1
0.3578 × 2 = 0.7156  -> 0
0.7156 × 2 = 1.4312  -> 1
0.4312 × 2 = 0.8624  -> 0
0.8624 × 2 = 1.7248  -> 1
0.7248 × 2 = 1.4496  -> 1
0.4496 × 2 = 0.8992  -> 0
0.8992 × 2 = 1.7984  -> 1
0.7984 × 2 = 1.5968  -> 1
0.5968 × 2 = 1.1936  -> 1
0.1936 x 2 = 0.3872  -> 0
0.3872 x 2 = 0.7744  -> 0
0.7744 x 2 = 1.5488  -> 1
0.5488 x 2 = 1.0976  -> 1
```

正序得到近似：

$$
0.6789 \approx 0.10101101110011_2
$$

**第四步：合并**：

$$
1234.6789 \approx 10011010010.10101101110011_2
$$

**第五步：规格化**：

IEEE 754 要变成： `1.xxxxxx x 2^n` ，也就是：

```
10011010010.10101101110011 = 1.001101001010101101110011 x 2^10
```

所以： `Exponent = 10`

**第六步：计算指数位**：

单精度偏移量 `Bias = 127` ，所以 `E = 10 + 127 = 137` ，将 `137` 转 8 位二进制：

```
137 = 10001001
```

**第七步：尾数 Mantissa**：

去掉前面的 `1.` ，并取**前 23 bit**：

```
Mantissa = 00110100101010110111001
```

**第八步：组合 32 位**：

```
Sign      1 bit   = 0
Exponent  8 bit   = 10001001
Mantissa 23 bit   = 00110100101010110111001
```

最终完整 32 位：

```
01000100100110100101010110111001
```

转成十六进制：

```
01000100 10011010 01010101 10111001
```

```
= 0x449A55B9
```

#### 4.2. `0.2555`

**第一步：确定符号位**：

`0.2555 > 0` ，所以符号位是 `0`

**第二步：整数部分转二进制**：

整数部分 = 0 ，所以

$$
0 = 0_2
$$

**第三步：小数部分转二进制（乘 2 法）**：

对 `0.2555` 进行转换：

```
0.2555 × 2 = 0.5110   -> 0
0.5110 × 2 = 1.0220   -> 1
0.0220 × 2 = 0.0440   -> 0
0.0440 × 2 = 0.0880   -> 0
0.0880 × 2 = 0.1760   -> 0
0.1760 × 2 = 0.3520   -> 0
0.3520 × 2 = 0.7040   -> 0
0.7040 × 2 = 1.4080   -> 1
0.4080 × 2 = 0.8160   -> 0
0.8160 × 2 = 1.6320   -> 1
0.6320 × 2 = 1.2640   -> 1
0.2640 × 2 = 0.5280   -> 0
0.5280 × 2 = 1.0560   -> 1
0.0560 × 2 = 0.1120   -> 0
0.1120 × 2 = 0.2240   -> 0
0.2240 × 2 = 0.4480   -> 0
0.4480 × 2 = 0.8960   -> 0
0.8960 × 2 = 1.7920   -> 1
```

得到：

$$
0.2555 \approx 0.010000010110100001_2
$$

**第四步：合并**：

$$
0.2555 \approx 0.010000010110100001_2
$$

**第五步：规格化**：

IEEE 754 要变成： `1.xxxxxx x 2^n` ，移动小数点：

```
0.010000010110100001
= 1.0000010110100001 × 2^(-2)
```

所以： `Exponent = -2`

**第六步：计算指数位**：

```
Bias = 127
E = -2 + 127 = 125
```

```
125 = 01111101₂
```

**第七步：尾数 Mantissa**：

去掉 `1.` ：

```
Mantissa = 0000010110100001...
```

补齐 23 位：

```
00000101101000010000000
```

**第八步：组合 32 位**：

```
Sign      = 0
Exponent  = 01111101
Mantissa  = 00000101101000010000000
```

合并：

```
00111110100000101101000010000000
```

转成十六进制：

```
00111110 10000010 11010000 10000000
```

```
= 0x3E82D080
```
